# Smart Retail Advanced App
Run in VS Code:
1. `python -m venv venv`
2. Windows: `venv\\Scripts\\activate`
3. `python -m pip install -r requirements.txt`
4. `python app.py`
5. Open http://127.0.0.1:5000
This is an advanced academic prototype with dashboard, inventory intelligence, forecast screen, segmentation and recommendations. Replace the demo CSV with the real cleaned project data before final submission.
